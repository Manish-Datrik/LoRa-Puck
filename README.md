# LoRa Puck PCB

## About the Project

This is a LoRa Puck PCB designed in EasyEDA. The purpose of this project was to learn how to design a real hardware board from scratch. It is mainly built for travel and outdoor use, where people can communicate over long distances even when there is no mobile network.

---

## Features

- Long-range LoRa communication
- USB Type-C for power and programming
- RP2040 Microcontroller
- SX1262 LoRa Module
- Small and compact PCB
- Low power design
- Suitable for travel and outdoor activities

---

## Tools Used

- EasyEDA
- RP2040
- SX1262 LoRa Module
- USB Type-C Connector
- AP2112 3.3V Regulator
- Crystal Oscillator
- Resistors
- Capacitors
- Inductors

---

## What I Did

- Created the project in EasyEDA.
- Added all the required components.
- Designed the complete schematic.
- Connected power, ground, USB, SPI, and LoRa signals.
- Checked all the electrical connections.
- Converted the schematic into a PCB layout.
- Placed the components properly for easy routing.
- Routed the PCB tracks neatly.
- Checked for design errors.
- Generated Gerber files for PCB manufacturing.
